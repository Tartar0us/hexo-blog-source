第二篇blog

* blog 更新指令
* hexo clean 清理当前缓存的静态页面
* hexo generate 生成新的静态页面
* hexo deploy 将生成的静态页面挂到github 之类的网站进行代理
* hexo server 启动本地服务器，预览静态页面
* hexo s -p 4010 当4000被占用时，可以开别的端口
