### 三、文本样式

- **粗体**：用两个星号`**`或两个下划线`__`包围文字。

markdown



```markdown
  **这是粗体文本**
  __这也是粗体文本__
```
    
- _斜体_：用一个星号`*`或一个下划线`_`包围文字。
    
    markdown
    
    复制
    
    ```markdown
    *这是斜体文本*
    _这也是斜体文本_
    ```
    
- ~~删除线~~：用两个波浪号`~~`包围文字。
    
    markdown
    
    复制
    
    ```markdown
    ~~这是删除线文本~~
    ```
    

### 四、列表

- **无序列表**：使用`-`、`+`或`*`作为列表标记。
    
    markdown
    
    复制
    
    ```markdown
    - 项目1
    - 项目2
    - 项目3
    ```
    
    或者
    
    markdown
    
    复制
    
    ```markdown
    + 项目1
    + 项目2
    + 项目3
    ```
    
    或者
    
    markdown
    
    复制
    
    ```markdown
    * 项目1
    * 项目2
    * 项目3
    ```
    
- **有序列表**：使用数字加点作为列表标记。
    
    markdown
    
    复制
    
    ```markdown
    1. 第一项
    2. 第二项
    3. 第三项
    ```
